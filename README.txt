BELLEZA ROSA - VERSION SIN SERVIDOR

Esta versión usa React + Vite y guarda productos, empleados, ventas y carrito en localStorage.
No necesita Express, Node backend, XAMPP, phpMyAdmin ni MySQL para ejecutarse como página frontend.

IMPORTANTE:
- Los datos se guardan solo en el navegador y dispositivo donde se usan.
- No se comparten entre el navegador del alumno y el del docente.
- Si se borra el almacenamiento del navegador, los datos pueden perderse.
- Esta versión no cumple una exigencia académica de backend Express/MySQL si la guía lo pide obligatoriamente.

PARA PUBLICAR EN VERCEL:
1. Sube estos archivos a un repositorio de GitHub.
2. En Vercel importa el repositorio.
3. Framework Preset: Vite.
4. Root Directory: ./ (si package.json está en la raíz).
5. Build Command: npm run build
6. Output Directory: dist
7. Deploy.

PARA PROBAR EN TU COMPUTADORA:
1. Instala Node.js.
2. Abre una terminal en la carpeta del proyecto.
3. Ejecuta: npm install
4. Ejecuta: npm run dev
5. Abre la URL local que indique Vite.

Los productos iniciales son demostrativos y pueden editarse desde la sección Productos.
